# Hệ thống quản lý trung tâm sửa xe

## 1. Giới thiệu đề tài

Đây là đồ án nhóm thuộc học phần **Công Nghệ Phần Mềm**, với đề tài **Quản lý trung tâm sửa xe**.

Đề tài hướng đến xây dựng một hệ thống hỗ trợ quản lý quá trình tiếp nhận xe, lập phiếu sửa chữa, quản lý phụ tùng, thanh toán và lập hóa đơn. Hệ thống cũng hướng đến hỗ trợ thống kê doanh thu, các loại xe và những lỗi thường gặp.

## 2. Công nghệ dự kiến

- **Ngôn ngữ:** Python
- **Framework:** Flask
- **Cơ sở dữ liệu:** MySQL
- **Giao diện:** HTML, CSS, Bootstrap

## 5. Trạng thái hiện tại

Nhóm đang trong giai đoạn phân tích yêu cầu và lên kế hoạch thực hiện. Các sơ đồ thiết kế, cơ sở dữ liệu và chức năng sẽ được cập nhật trong quá trình phát triển.

## 6. Mục đích repository

Repository được sử dụng để giới thiệu đề tài, lưu trữ tài liệu và theo dõi quá trình phát triển hệ thống. Source code sẽ được cập nhật sau khi nhóm hoàn thành giai đoạn phân tích và thiết kế.
