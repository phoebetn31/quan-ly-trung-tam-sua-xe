# Bản chuyển cấu trúc (demo)

Chạy từ thư mục gốc: `python -m pip install -r requirements.txt`, `python -m flask --app app run`.

Tài khoản demo cũ: admin / 123456. Chưa có session, phân quyền, CSRF hoặc CSDL; không triển khai công khai. Dữ liệu JSON gốc nằm trong instance/ (không commit). Các thư mục nghiệp vụ khác để trống. CRUD nhân viên giữ để tái sử dụng cho CF02, chưa phải CF02 hoàn chỉnh. Không ghi đè __init__.py của dự án thật nếu đã có cấu hình. index.html cũ trống nên bỏ.
